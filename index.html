Manual de Usuario

Gestor Depósito Inteligente y Rentabilidad Real

Este manual explica paso a paso cómo utilizar cada módulo del sistema y detalla la lógica detrás de los cálculos de precios, costos variables y la rentabilidad real del negocio.

1. Módulo: Stock y Costos

Este módulo es el cimiento del sistema. Aquí se registran todos los artículos del depósito. Podés cargar los productos de a uno de forma manual o subir un archivo Excel completo descargando primero la plantilla base. El sistema tiene la inteligencia para reconocer las columnas automáticamente, pero siempre es mejor usar la plantilla.

Regla de oro para los costos: Es fundamental que todos los Costos Unitarios se carguen SIN IVA (si la empresa es Responsable Inscripto). El IVA no es dinero de la empresa, es un impuesto que se recauda para la entidad fiscal (ARCA). Si cargás los costos con IVA, el cálculo de rentabilidad de tu empresa será completamente irreal.
  • Control Físico: Visualizá rápidamente qué productos están agotados (en rojo) o por quedarse sin stock.
  • Costo Capital: El sistema calcula cuánta plata hay inmovilizada en mercadería basándose en la cantidad de unidades por el costo unitario.

2. Módulo: Listas de Precios y Lógica de Márgenes

Aquí configurás a qué precio vas a vender. El sistema abandona la vieja práctica de "poner precios a ojo" y utiliza una fórmula de cálculo automático. Para cada lista de precio (Ej: "Mercado Libre", "Mayorista"), tenés que definir dos porcentajes:

  1. Remarque al Costo (%): Es el porcentaje que le sumás a tu Costo Base para formar el Precio de Venta.
  2. Costo Variable de Lista (%): ¡El gran olvidado! Aquí debés incluir las comisiones de la plataforma y los impuestos sobre estas ventas como Ingresos Brutos y otros costos financieros. Si tenés 3% de IIBB y 3,6% de comisión, el total sería 6,6%.
El mito del porcentaje de ganancia: Muchos emprendedores creen que si le agregan un 40% al costo, su ganancia es del 40%. Esto es un error grave. La ganancia se mide sobre el precio de venta final, no sobre el costo.
Ejemplo de la lógica correcta:
- Costo del producto (sin IVA): $10.000
- Remarque aplicado: 40%
- Precio de Venta: $14.000
- Cálculo engañoso: $14.000 - $10.000 = $4.000 (Parece que ganás 40%)

Cálculo Real que hace el sistema:
Si dividimos esos $4.000 de ganancia entre los $14.000 del precio de venta, nos da un 28,5%. Esto es lo que estás ganando en realidad, no un 40%.
A esto, el sistema le va a restar tus Costos Variables (ese 6,6% del ejemplo anterior). Esa diferencia es tu Contribución, que es lo que te sirve para cubrir los costos fijos.

3. Módulo: Operaciones (Flujo de Venta)

Para respetar el flujo real del local, la venta se divide en pasos controlados, registrando siempre quién generó la operación:

  1. Punto de Venta / Presupuestos: Lo primero es seleccionar el Cliente y el Vendedor en la parte superior. El sistema recordará tu nombre de vendedor para la próxima venta automáticamente. Luego se arma el carrito buscando los artículos y se selecciona "Crear Presupuesto". El presupuesto genera un PDF (con el nombre del vendedor impreso) y queda guardado en estado Pendiente, sin descontar stock. También se puede usar "Cobrar Directo" para agilizar ventas rápidas de mostrador.
  2. Cobro (Caja): Cuando el cliente abona, el encargado de caja selecciona "Cobrar" en el presupuesto. En este momento se descuenta el stock real y el dinero ingresa al cierre diario separado por medio de pago, dejando registrado quién fue el vendedor que concretó la operación para facilitar el cálculo de comisiones.
  3. Depósito / Remitos: Una vez cobrada, la operación aparece en la pestaña de Depósito. El personal del depósito visualiza qué mercadería ya está pagada y lista para salir, imprimiendo el Remito oficial de entrega (que ahora también incluye al vendedor responsable de la venta).

Desglose de Caja: La caja separa el balance del día en tres grandes grupos para que sepas exactamente dónde está la plata: Efectivo Físico (billetes a contar), Mercado Pago y Transferencias.

4. Módulo: Rentabilidad General

Es el tablero definitivo. A fin de mes, esto te dirá si la estructura está comiendo tu ganancia o si realmente ganaste plata.

  • 1. Ventas Totales: Suma de los ingresos brutos del mes (sin IVA).
  • 2. Costo Directo (CMV): Los costos variables que NO son las compras del mes, sino lo que te costó comprar *específicamente* los artículos que vendiste este mes.
  • 3. Costos Variables: Comisiones e impuestos (IIBB, etc.) de las ventas generadas.
  • 4. Margen de Contribución: La plata que "sobra" de las ventas para hacer frente a los fijos.
  • 5. Gastos Fijos: Sueldos (incluyendo el tuyo como dueño), alquiler, luz, cargas sociales. Se cargan manualmente con el botón "+".
  • RESULTADO NETO: Si el número final es verde, es tu ganancia real. Si es rojo, estás operando a pérdida.

5. Módulo: Base de Clientes

Directorio de compradores. Al cobrar un presupuesto asignado a un cliente, el sistema arma un Historial de Compras. Podés ver las fechas, qué llevó y cuánta plata lleva gastada en total. También permite subida masiva vía Excel.

6. Módulo: Configuración

Un espacio para colocar el nombre de la empresa, subir el logo y establecer el PIN de seguridad. Estos cambios se guardan en el navegador y se reflejan en toda la aplicación.
